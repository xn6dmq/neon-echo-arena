NEON ECHO ARENA is an original twin-stick arena shooter that runs offline in a desktop browser from static files: move with WASD or the arrow keys, aim and fire with the mouse, and survive 10 waves. Every destroyed enemy emits an expanding echo ring that damages the pack around it, and enemies destroyed by a ring emit their own — so the best shot is the one that starts a chain.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step and no network requests: the game is the plain files under `game/`, and all of its sound is synthesised live with WebAudio.
